# Примеры для MATLAB

Добро пожаловать в репозиторий **orion-daq-matlab-exаmples**! 

Здесь собраны примеры на MATLAB, которые помогут вам освоить взаимодействие с RESTful API систем сбора данных ORION.

В каждую систему ORION встроен сервер - QServer. Он обеспечивает доступ через API для удаленного конфигурирование устройств, управление измерениями и  получения данных. 

Рекомендуем вам начать с «базовых» примеров в порядке, указанном ниже:

1. **BasicsItemList**
    
    Начните с этого примера, чтобы научиться получать список элементов от QServer и понимать их структуру. Он закладывает основу взаимодействия QServer REST API, демонстрируя, как запрашивать и парсить данные с сервера. 
    
2. **BasicsConfigureItems** 
    
    После первого примера переходите к этому, в котором вы узнаете, как настраивать режимы работы и параметры элементов.  Пример научит вас вносить изменения в конфигурацию QServer.
    
3. **BasicsStreamData** 
    
    Следующим шагом будет пример по работе с потоковыми данные из QServer. Основное внимание здесь уделено установлению потоковой передачи и обработке данных в реальном времени..
    

Следуя этой последовательности примеров, вы получите знания, необходимые для выполнения базовых операций, и создадите основу для более сложного взаимодействия QServer и MATLAB.

Желаем успехов в освоении материала!
